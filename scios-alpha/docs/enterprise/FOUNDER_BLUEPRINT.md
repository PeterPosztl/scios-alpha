## Why it exists

Enterprise AI today fragments into chatbots, dashboard piles, agent swarms, and role-specific apps that cannot share one decision spine.

SCI OS ×10 exists to be a **unified enterprise intelligence operating environment**: one product where professionals move from data to governed action with uncertainty, risk, evidence, and lineage intact — not a demo cockpit and not 200 copied applications.

---

## What we are creating

### Product shape

```
DATA → CONTEXT → INTERPRETATION → PREDICTION → UNCERTAINTY
  → RISK → GOVERNANCE → DECISION → ACTION/SIMULATION
  → OUTCOME → EVIDENCE → LINEAGE
```

Above that spine: a **professional experience layer** (role + job-to-be-done + object + workflow + policy → Experience Compiler → workspace).

### Immutable philosophy

| Rule | Meaning |
|------|---------|
| EVIDENCE > CLAIM | No PASS without artifact |
| UNKNOWN ≠ PASS | Honesty over vanity |
| NO FALSE READY | ALPHA ≠ enterprise GO |
| RISK > PREDICTION | Prediction never outranks risk |
| GOVERNANCE > AGENT | Agents propose; policy decides |
| NO_ACTION IS VALID | Abstention is a first-class outcome |
| SIMULATION ≠ LIVE | First release is simulation-only |
| FULL LINEAGE | Provenance is product, not debug |
| HUMAN OVERRIDE | Consequential acts need humans |
| ONE CANONICAL PRODUCT | No parallel “OS” authorities |
| ONE CANONICAL BOOT | One boot state machine |

### Scale model (200+ professions)

**Composition, not duplication:**

`ROLE + JTBD + OBJECT + WORKFLOW + PERMISSIONS + DATA + CAPABILITIES + RISK + POLICY + UX LEVEL → Experience Compiler → workspace`

Role definitions are **data/config**. We do not ship 200 hardcoded apps.

### What it is not

- A chatbot
- A collection of dashboards
- 200 separate applications
- An unsupervised agent swarm
- A developer-only technical cockpit as the primary product

## Success definition (founder)

A professional opens SCI OS and immediately understands:

where they are · what matters · what changed · what can be investigated · what requires a decision · what AI concluded · how certain it is · what risk exists · what actions are permitted · why · where the evidence came from.
