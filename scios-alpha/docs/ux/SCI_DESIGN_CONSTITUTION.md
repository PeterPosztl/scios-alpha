# SCI Design Constitution

**Authority:** Product Memory (`product-memory/`) + this document  
**Label:** ALPHA_NON_PRODUCTION  
**Rule:** Learn from external systems; never become them.

---

## Purpose

SCI OS UX must remain a **professional intelligence operating environment**: decision-first, evidence-native, risk- and governance-visible — not a developer cockpit and not a vendor clone.

---

## Principles (mandatory)

1. **Professional, not developer-centric** — Default surfaces speak jobs-to-be-done, not ports/services/JSON.
2. **Decision-first** — Attention → what matters → what to decide next.
3. **Evidence-native** — Every consequential result exposes a path to evidence/lineage.
4. **Uncertainty-visible** — Abstention, intervals, and NON-PRODUCTION calibration are first-class.
5. **Risk-visible** — Risk is never buried under prediction confidence theater.
6. **Governance-visible** — Policy outcomes and human approval are explicit; proposals ≠ completed actions.
7. **Progressive disclosure** — ATTENTION → MEANING → RECOMMENDATION → UNCERTAINTY → RISK → DECISION → ACTION → WHY → EVIDENCE → TECHNICAL LINEAGE.
8. **High information density without chaos** — Hierarchy, density modes, and calm surfaces beat dashboard litter.
9. **Same object, different role lens** — One Entity/Case truth; role changes priority, presentation, actions, terminology — not underlying facts.
10. **Technical detail on demand** — Technical View is deliberate, not the default.
11. **No dead-end actions** — Visible controls have actionId, handler, loading/success/failure, and result/evidence state.
12. **Clear degraded states** — Capability failure isolates; no false READY; no false total failure.
13. **Accessible by design** — Keyboard, focus, contrast, semantics, reduced motion, density modes (COMFORTABLE / STANDARD / EXPERT).
14. **Consistent cross-domain interaction** — Shared task grammar and Experience Contracts across roles.

## Visual identity (SCI genome)

Preserve Swiss-minimal SCI language:

| Token | Role |
|-------|------|
| Snow / Fog | Surfaces / atmosphere |
| Graphite | Secondary text |
| Deep Navy | Primary text / actions |
| Swiss Red | Critical / reject |
| Ice Blue | Focus / selection / trust affordances |

Do **not** adopt purple-indigo AI clichés, vendor skins, or random hardcoded palettes outside tokens.

## Sequence discipline

```
BOOT → HOME → UX BASELINE CAPTURE → DESIGN SYSTEM NORMALIZATION
  → EXPERIENCE CONTRACTS → EXPERIENCE COMPILER → ROLE EXPANSION
```

Do not redesign cosmetics to hide boot defects.
